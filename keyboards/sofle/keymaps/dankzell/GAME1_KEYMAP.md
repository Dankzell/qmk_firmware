# _GAME1 Layer Visual Keymap

This keymap is optimized for left-handed gaming, placing all essential gaming keys on the right side while providing function keys and navigation on the left side.

## Layout Overview

```

│              LEFT SIDE                  │    │              RIGHT SIDE                 │
│         (Function & Navigation)         │    │            (Gaming Area)                │
└─────────────────────────────────────────┘    └─────────────────────────────────────────┘
```

## Key Functions by Zone

### Left Side - Utility & Navigation
**Top Row (Function Keys):**
- `F1` - `F6`: Quick access to function keys
- `F7` - `F12`: Extended function keys

**Home Row (Navigation):**
- Arrow Keys: `↑` `←` `↓` `→` for menu navigation
- `Page Up` / `Page Down`: Scrolling through lists/inventory

**Bottom Row (System Keys):**
- `Ctrl` / `Alt`: Essential modifier keys for shortcuts
- `Home` / `End`: Quick navigation
- `Insert` / `Delete`: Text editing utilities

**Thumb Keys:**
- `Enter`: Confirm actions
- `Space`: Alternative action key

### Right Side - Gaming Core
**Top Row (Numbers):**
- `ESC`: Quick menu access/cancel
- `1` - `5`: Weapon/item slots, hotkeys

**Home Row (Movement):**
- `6`: Additional hotkey slot
- `Q` `W` `E` `R` `T`: Primary gaming keys
  - `W`: Forward movement (or whatever you assign)
  - `Q` `E`: Strafe/rotate
  - `R` `T`: Action keys

**Middle Row (Actions):**
- `TAB`: Scoreboard/map toggle
- `A` `S` `D` `F` `G`: Secondary action keys
  - `A` `S` `D`: Movement alternatives
  - `F` `G`: Interaction keys

**Bottom Row (Combat):**
- `Shift`: Run/sprint modifier
- `Z` `X` `C` `V` `B`: Additional action keys
  - `Z` `X`: Crouch/prone
  - `C` `V`: Communication/voice
  - `B`: Additional hotkey

**Thumb Keys:**
- `Space`: Jump/primary action
- `Enter`: Chat/confirm

## Usage Tips

1. **For FPS Games**: Use right thumb for jump (`Space`), right pinky for sprint (`Shift`)
2. **For RPGs**: Numbers 1-5 for spells/items, F-keys for quick saves
3. **For Strategy**: F-keys for unit groups, numbers for building hotkeys
4. **Navigation**: Use left side arrow keys for menu navigation while keeping right hand on mouse

## Key Advantages

- **Left-handed friendly**: All gaming essentials on the right side
- **Mouse space**: Left side is clear for mouse movement
- **Function access**: F1-F12 readily available for game-specific functions
- **Navigation**: Dedicated arrow keys and page navigation
- **Modifier keys**: Ctrl/Alt available for shortcuts without interfering with gaming

## Layer Toggle

Access this layer using the `ESC + TAB` combo from the base layer to toggle _GAME1 on/off.
